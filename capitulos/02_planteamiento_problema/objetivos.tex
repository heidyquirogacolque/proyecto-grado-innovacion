\section{Objetivos}
\label{sec:objetivos}

\subsection{Objetivo general}

Desarrollar e implementar el SISTEMA WEB DE INSCRIPCIÓN PARA EL MÓDULO TECNOLÓGICO PRODUCTIVO SAN JULIÁN BTH --- VERSIÓN 2.0, mediante una arquitectura cliente-servidor basada en HTML5, CSS3, JavaScript, PHP y PostgreSQL, para garantizar la recuperación autónoma de credenciales, el registro documental de la matriculación y la asignación automatizada a cursos y paralelos según la unidad educativa de origen, asegurando un proceso escolar equitativo, eficiente y transparente.

\subsection{Objetivos específicos}

\begin{itemize}
    \item Diagnosticar las deficiencias operativas y los requerimientos funcionales del proceso de inscripción y matriculación en el BTH de San Julián, mediante encuestas y entrevistas a la comunidad escolar.
    \item Diseñar la arquitectura del sistema web, los modelos de base de datos y la interfaz de usuario para la gestión de credenciales, matriculación documental y distribución de cursos y paralelos.
    \item Desarrollar los módulos del sistema web de inscripción (Versión 2.0) utilizando tecnologías HTML5, CSS3, JavaScript, PHP y PostgreSQL.
    \item Evaluar el funcionamiento operativo y el impacto socioeducativo del sistema desarrollado, mediante pruebas funcionales y medición de la satisfacción de los usuarios.
\end{itemize}
